# 校長的一天（青禾國小）

像素風的校長模擬遊戲。你是虛構的中型國小「青禾國小」的新任校長，用方向鍵在校園裡走動，處理一天之中接連而來的人和事。

## 怎麼玩

下載 `校長的一天.html`，用瀏覽器直接打開即可，不需要安裝，也不連網。

- 方向鍵：走動
- 靠近人物或事件，按空白鍵或 Enter 互動
- T 鍵：原地等 15 分鐘
- 辦公桌：批公文、休息、結束今天
- 遊戲內時間會自己走（現實 0.6 秒 = 遊戲 1 分鐘），對話時暫停

## 學期的 10 個關鍵日

1. 開學日（9/1）
2. 第一次校務會議（9/3）
3. 班親會（9/17）
4. 公開觀課日（10/1）
5. 颱風後的突發（10/7，會下雨）
6. 校慶運動會籌備（11/3）
7. 經費核銷日（11/19）
8. 疑似霸凌通報（12/2）
9. 校務評鑑日（12/17）
10. 期末與下學年規劃（1/14）

前面的決定會影響後面：例如第 4 天有沒有留意到小宇，會決定第 8 天霸凌案的證據夠不夠；第 6 天的採購做法，會影響第 7 天的內部稽核。學期結束時依累積的決定與紀錄，推算校務評鑑等第，並附領導風格分析與討論題。

## 設計說明

- 對象：校長培訓學員。每個選擇都對應一種領導模式，每天結束時揭曉，並附理論引用與反思題。
- 單一 HTML 檔，零後端，劇本全部離線寫好。
- 學校、人物、事件皆為虛構。
