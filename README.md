# 校長的一天（青禾國小）

像素風的校長模擬遊戲。你是虛構的中型國小「青禾國小」的新任校長，用方向鍵在校園裡走動，處理一天之中接連而來的人和事。

## 怎麼玩

下載 `校長的一天.html`，用瀏覽器直接打開即可，不需要安裝，也不連網。

- 方向鍵：走動
- 靠近人物或事件，按空白鍵或 Enter 互動
- T 鍵：原地等 15 分鐘
- 辦公桌：批公文、休息、結束今天
- 遊戲內時間會自己走（現實 0.6 秒 = 遊戲 1 分鐘），對話時暫停

## 目前進度

學期共 10 個關鍵日，目前完成第 1、2 天：

1. 開學日 ✅
2. 第一次校務會議 ✅
3. 班親會
4. 公開觀課日
5. 颱風後突發
6. 校慶運動會籌備
7. 經費核銷
8. 疑似霸凌通報
9. 校務評鑑
10. 期末與下學年規劃

## 設計說明

- 對象：校長培訓學員。每個選擇都對應一種領導模式，每天結束時揭曉，並附理論引用與反思題。
- 單一 HTML 檔，零後端，劇本全部離線寫好。
- 學校、人物、事件皆為虛構。
